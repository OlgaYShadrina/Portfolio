### 🤖 AI-проекты (стажировки)

#### 1. Система нейро-контроля качества колл-центра (NiceCase)

**Суть проекта:**
Компания NiceCase — оператор колл-центра — хотела автоматизировать контроль качества работы операторов. Вручную прослушивать сотни звонков и оценивать их по десяткам параметров было долго, дорого и субъективно. Задача проекта — создать интеллектуальную систему, которая анализирует записи звонков с помощью GPT-моделей, оценивает работу менеджеров, выявляет ошибки и формирует рекомендации по улучшению обслуживания.

**Что сделала:**
- Разработала промпт для оценки по категории «Доволен ли клиент», провела сравнительный анализ GPT-моделей
- Собрала текстовые диалоги «клиент-менеджер» и сформировала эталоны на их основе
- Провела транскрибацию диалогов, сравнила результаты моделей Whisper и Tinkoff по метрикам
- Отработала получение итогового отчёта по качеству услуги в формате PDF

**Стек:** Python, GPT-модели, Whisper, Tinkoff STT, Jupyter Notebook
🔗 [Ссылка на проект](https://ai-hunter.ru/dobryakov)

#### 2. Система прогнозирования износа колёс локомотива (РЖД)

**Суть проекта:**
РЖД эксплуатирует тысячи локомотивов, и преждевременный износ колёсных пар — серьёзная проблема: это простой, дорогостоящий ремонт и риски безопасности. Задача проекта — построить модель, которая прогнозирует износ колёс на основе данных эксплуатации и позволяет перейти от планового ремонта к предиктивному (по фактическому состоянию). Это снижает затраты и повышает надёжность перевозок.

**Что сделала:**
- Провела поиск и детальный анализ научных материалов по теме
- Провела анализ и обработку данных заказчика
- Построила корреляционные матрицы, расширила датасет дополнительными параметрами
- Построила модели при помощи AutoKeras, подобрала архитектуру генетическим алгоритмом

**Стек:** Python, Pandas, AutoKeras, корреляционный анализ
🔗 [Ссылка на проект](https://ai-hunter.ru/iznoskoles)

#### 3. Нейроменеджер чата с выявлением потребностей клиентов (МЦ Доверие)

**Суть проекта:**
Медицинский центр «Доверие» хотел автоматизировать первичную коммуникацию с пациентами: отвечать на типовые вопросы, выявлять потребности (какая услуга нужна, к какому специалисту) и направлять к нужному врачу или администратору. Задача проекта — создать нейроконсультанта, который ведёт диалог, опираясь на базу знаний клиники, и передаёт «горячих» клиентов в работу.

**Что сделала:**
- Парсинг информации с сайта заказчика, написание скриптов предобработки данных
- Составление базы знаний нейроконсультанта
- Работа с LLM моделями и API ChatGPT
- Тестирование и проработка гипотез по повышению точности модели

**Стек:** Python, LLM, API ChatGPT, парсинг
🔗 [Ссылка на проект](https://ai-hunter.ru/mcdoverie)

#### 7. Автоматизация процессов учёта и логистики

**Суть проекта:**
Компания (прачечная) вела учёт заказов и логистику вручную: Excel, бумажные журналы, устные договорённости между сменами. Это приводило к ошибкам, потерям заказов и долгой обработке. Задача проекта — проанализировать текущие процессы, выявить узкие места и предложить решение для автоматизации учёта и логистики.

**Что сделала:**
- Провела интервью со стейкхолдерами, описала процесс AS-IS в BPMN 2.0
- Выявила 4 узких места, разработала модель TO-BE
- Составила ТЗ на автоматизацию, провела тестирование с заказчиком

**Стек:** BPMN, UML, Miro, Draw.io, ТЗ
